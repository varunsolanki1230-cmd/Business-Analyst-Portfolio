# 📊 Project 1 – E-Commerce Sales Analysis Dashboard

### Overview

This project analyzes a fictional Indian e-commerce sales dataset using Microsoft Excel. The objective was to clean the data, analyze sales performance, and build an interactive dashboard for business decision-making.

### Tools Used

- Microsoft Excel
- Data Cleaning
- PivotTables
- PivotCharts
- Dashboard Design

### Dashboard

![Dashboard](E%20COMMERCE%20SALES%20ANALYSIS%20DASHBOARD.png)

### Key KPIs

- 💰 Total Sales: ₹62,85,630
- 📦 Total Orders: 99
- 📈 Average Order Value: ₹63,491
- 📍 Top Performing City: Bengaluru

### Key Business Insights

- Bengaluru generated the highest sales.
- Smartphones were the highest-performing category.
- Apple AirPods Pro generated the highest product revenue.
- Interactive dashboard created for management reporting.
